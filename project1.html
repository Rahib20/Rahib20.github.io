The idea

I wanted to create an application that could help users become more familiar with UK road signs through a combination of learning and testing.

Users can create an account, choose a road sign category and either study individual signs or take a multiple-choice quiz.

After completing a quiz, users can review their answers and see their results, helping them identify areas where they could improve.

What I built

Key features

01 / USER ACCOUNTS

Login & Registration

Users can register and log in to the application. Input validation and feedback messages help handle missing details and unsuccessful logins.

02 / LEARNING

Learn Mode

Users can browse road signs by category, viewing each sign alongside its name and description before taking a quiz.

03 / TESTING

Multiple-Choice Questions

The test mode presents road sign questions with four possible answers, allowing users to test their knowledge and track scores.

04 / RESULTS

Results & Answer Review

Users can review quiz results, look back at incorrect answers and see category performance. SQL queries connect the application to its Access database.

Looking back

What I learned

An early step into building applications

This project helped me develop my understanding of programming logic, form validation, user interfaces and relational databases. I gained experience using SQL queries from Visual Basic to interact with Microsoft Access and learned how different application components work together. It was a useful starting point for the more complex software projects I worked on later.
