Football Data
Pipeline.

A project combining football, Python and the Elastic Stack. I built a Flask API to generate fictional player data, then used Elasticsearch and Kibana to explore the results through dashboards.

I also captured and analysed HTTP request logs from the Flask app. That gave me two different dashboards: one for football player data and another for API requests and application activity.

What I worked with

Building and troubleshooting the pipeline

Technical experience

This project brought together a Flask API, data generation, containerised services, Elasticsearch indexing and Kibana visualisations. I also worked with Filebeat and Logstash for the logging side of the pipeline.

Docker and Jenkins were part of exploring how to build and run the connected services and automate aspects of the workflow.

What the dashboards taught me

The player dashboard demonstrated how generated data could become useful statistics, while the logs dashboard showed how the same project could be monitored through its HTTP requests.

Seeing request methods, status codes, paths and individual log entries in Kibana helped connect application behaviour to the data collected by the pipeline.

Why this project matters to me

I wanted to build something that combined a subject I enjoy football with hands-on experience in APIs, data pipelines and observability. The result was more than a football dashboard: it was also a way to see how requests flow through an application and how logging tools make that activity visible.
