University · Final-year project

YourHired.

A web-based rota and employee management system built using Python and Django, bringing shift schedules, holiday requests, shift cover and employee information into one place.

The idea came from challenges I experienced at work at the time. Checking rotas and pay information meant using different systems, while finding cover for a shift could mean asking a manager to coordinate everything.

For my final-year project, I explored how a single platform could make these everyday tasks more straightforward for employees and managers.

Behind the idea

About the project

A practical idea inspired by workplace scheduling, developed as my Computer Science final-year project.

The problem

At my workplace at the time, rotas and pay information were managed through separate platforms. Employees had to go to different places to find details they needed.

Shift cover could be inconvenient too. If someone could not work, they often had to tell a manager, who would then try to find another employee willing to cover.

I wanted to explore a simpler approach that brought these tasks together.

The solution

01
Employee self-service

View rotas, request time off and offer or accept shifts through the website.

02
Manager tools

Create shifts, update employee details and review holiday requests.

03
One connected application

Bring employee profiles, schedules, holiday requests and shift offers together.

Inside the application

Key features

Features developed for the different needs of employees and managers.

01 / EMPLOYEES

View Work Rotas

Employees can see the shifts assigned to them, including dates and times, from their own account.

02 / TIME OFF

Request Holidays

Submit holiday requests and check whether they are pending, approved or denied.

03 / SHIFT COVER

Offer and Accept Shifts

Offer an assigned shift to colleagues, or accept a shift another employee has offered.

04 / MANAGERS

Create and Edit Rotas

Managers can add and modify shifts when organising employee schedules.

05 / APPROVALS

Manage Time-Off Requests

Managers can review requests and approve or deny them, with the status shown in the application.

06 / STAFF

Employee and Pay Details

Add new employees and manage information such as positions and pay details.

Looking back

What I learned

Learning Django through a real problem

YourHired was my first project using Django and Python as a web backend. It pushed me to learn about models, forms, views and templates while developing a system with different types of users. I gained experience translating workplace problems into features, designing related data and connecting frontend interactions to backend logic. The project was built for university, rather than deployed as a production workplace system.
