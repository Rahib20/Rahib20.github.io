Featured project · Data & Automation

Football Data Pipeline

A project that brings together football, Python and data visualisation. I built a Flask API that generates fictional football player data, then created a pipeline to process the information and display it in interactive dashboards.

The project also uses Docker and Jenkins to explore containerisation, automated builds, testing and deployment.

Python Flask Elasticsearch Logstash Filebeat Kibana Docker Jenkins
Read more about this project

The idea: Generate synthetic football player records and make the data useful through searchable dashboards.

How it works: A Python Flask application generates data, Filebeat and Logstash help collect and process it, Elasticsearch stores it, and Kibana lets users explore player statistics.

What I explored: Data pipelines, REST APIs, containers, CI/CD, visualisation and troubleshooting across multiple connected services.
