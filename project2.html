Behind the idea

About the project

Building a language-learning experience around interaction rather than just memorisation.

The concept

Learning a language involves understanding how to communicate in different situations, not just remembering individual words.

Our group explored a role-play approach where users could choose a learning level and practise conversations based on different everyday contexts.

For example, a user can select a scenario involving asking for directions, choose a role and then progress through a conversation task.

The interface also includes help features, such as hints and translations, to support users while they complete the activity.

Inside the application

Key features

The main features demonstrated in the application's interface.

01 / LEVELS

Choose a Learning Level

Users can select from four levels: A1, A2, B1 and B2, giving them different options for their language-learning activities.

02 / CONTEXT

Context Selection

Users can search for tasks based on contexts such as introductions or asking and giving directions.

03 / FUNCTIONS

Language Functions

The application provides options for selecting language functions, allowing users to find activities focused on particular types of communication.

04 / ROLES

Role Selection

Users choose between Role A and Role B before beginning a scenario. The interface also displays a validation message if no role has been selected.

05 / PRACTICE

Interactive Role-Playing

Users move through a guided conversation one prompt at a time. A progress indicator shows how far they have moved through the activity.

06 / SUPPORT

Hints & Translations

The interface provides help options during activities, including a hint button and translation-related pop-ups.
