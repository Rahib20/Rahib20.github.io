## Featured Projects

### ⚽ Football Data Pipeline

A personal project combining my interest in football with data engineering and observability.

I used Python and Flask to generate fictional football player data, then explored and visualised it using Elasticsearch and Kibana.

The project includes a player statistics dashboard and a separate dashboard for monitoring API requests and application logs.

**Technologies:** Python, Flask, Elasticsearch, Kibana, Logstash and Filebeat.

[View Project](project4.html) | [View Source Code](https://github.com/Rahib20/schema-generator)

### 📅 YourHired — Rota Management System

My final-year university project, built using Python and Django.

YourHired is a web application designed to help managers and employees organise shifts, manage holiday requests and coordinate work schedules.

The project page includes a video demonstration and screenshots of the implementation.

**Technologies:** Python, Django, HTML, CSS and databases.

[View Project](project3.html)

### 🌍 Role-Play Language Learning Application

A university group project designed to help users practise different languages through interactive role-play scenarios.

My contributions focused on database design and retrieving conversation prompts for the application.

**Skills:** Database design, collaborative development and problem-solving.

### 🚦 Road Signs Quiz

A desktop application developed during college to help users learn and recognise UK road signs.

The application includes learning activities, quizzes, different road sign categories and result tracking.
